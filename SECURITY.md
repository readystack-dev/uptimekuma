# Security policy: Uptime Kuma build kit

To report a vulnerability in this build kit or in the `readystack/uptimekuma` image, email support@readystack.dev (the contact in https://readystack.dev/.well-known/security.txt). Please do not open a public issue for it.

A vulnerability in Uptime Kuma itself belongs with its upstream project (https://github.com/louislam/uptime-kuma); ReadyStack ships upstream's fix in its next release.

Every ReadyStack release is scanned again every day; known defects of each release are in this repository's Issues and at https://readystack.dev/defects.html?product=uptimekuma.
